<h2>🚀 О приложении</h2>

<p>
  <strong>«АвтоТех» Desktop</strong> — это десктоп-клиент для сотрудников автосервиса. Он входит в экосистему «АвтоТех» и позволяет:
</p>

<ul>
  <li>📋 Управлять заказами клиентов (статусы, добавление, удаление)</li>
  <li>👥 Редактировать базу клиентов, контактов и отзывов</li>
</ul>

<hr>

<h2>🔧 Установка и запуск</h2>

<p><strong>Шаг 1:</strong> Убедитесь, что у вас установлен <code>Node.js</code> (версия 16+) и запущен основной сервер (см. главную ветку <code>main</code>).</p><br />

<p><strong>Шаг 2:</strong> Клонируйте ветку application:</p>

<pre>
git clone -b application https://github.com/gaspacho2103/autotechnical.git
cd autotechnical
</pre>

<br />

<p align="center">
  <img width="581" height="370" alt="image" src="https://github.com/user-attachments/assets/e9e1dc7d-d48f-42ab-8c4f-9c8ed7fb7e4f" />
</p><br />

<p><strong>Шаг 3:</strong> Установите зависимости:</p>

<pre>
npm install
</pre>

<p><strong>Шаг 4:</strong> Настройте подключение к API. Откройте файлы .js и поменяйте ссылки в await fetch на адрес хоста, на котором у вас установлено API</p>

<br />

<p><strong>Шаг 5:</strong> Запустите приложение:</p>

<pre>
npm start
</pre>

  ✅ <strong>Готово!</strong> Приложение запустится в отдельном окне.
